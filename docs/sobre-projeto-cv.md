# Bullet Points para Currículo - Projeto Ongoing

## Opção 1 (Foco em Arquitetura e Qualidade)

- **Desenvolveu** uma API RESTful em **Java 25** com **Spring Boot 4** para centralizar o controle de assinaturas
  recorrentes pessoais, aplicando arquitetura em camadas, migrações com **Flyway** e mapeamento de DTOs com **MapStruct
  **, alcançando 80% de cobertura com testes de integração (**Testcontainers** + **RestAssured**) e deploy contínuo em
  produção via **Railway**.

## Opção 2 (Foco em Stack Moderna e Deploy)

- **Projetou** sistema de gerenciamento de assinaturas para eliminar gastos recorrentes desnecessários, utilizando *
  *Java 25**, **Spring Boot 4** e **PostgreSQL** (Neon), com pipeline CI/CD no **GitHub Actions** executando testes de
  integração automatizados, resultando em aplicação estável em produção com 80% de cobertura de testes seguindo
  abordagem API First.

## Opção 3 (Foco em Aprendizado e Boas Práticas)

- **Implementou** API de controle financeiro de assinaturas para aprofundar conhecimentos em **Spring Boot 4**,
  estruturando o projeto com **Clean Code**, testes de integração robustos usando **Testcontainers** e **RestAssured** (
  80% de cobertura), e infraestrutura de produção com **Railway** e **PostgreSQL** no Neon.
